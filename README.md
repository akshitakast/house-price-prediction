# House Price Prediction

A data science project that predicts house prices based on features like location, 
size, and amenities using regression models. Includes data cleaning, exploratory 
data analysis (EDA), feature engineering, and model evaluation.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib/Seaborn

## Project Structure
- `house_price_prediction.ipynb` — main notebook with EDA, preprocessing, and model training
